# Android setup

This repository contains the Flutter/Dart application source. Android Studio/Flutter generates the platform Gradle wrapper and standard Android files when creating the Flutter project.

For Firebase, place the downloaded `google-services.json` in `android/app/` after creating your Android app in Firebase. Keep it out of a public Git repository unless you have deliberately configured the repository/security policy for it.

Before release, configure your application ID, signing key, AdMob App ID metadata, and Firebase settings.
